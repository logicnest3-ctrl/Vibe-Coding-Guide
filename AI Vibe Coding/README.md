# Ultimate Web Application QA Checklist

This repository contains the strict design philosophy, technical standards, SEO guidelines, and performance benchmarks for deploying clean, utility-driven web applications.

## 🚫 Strict Exclusions (The Anti-Slop List)
-  No purple gradients or pill-shaped buttons
-  No fake reviews, customer counters, or fake metrics
-  No AI slop copy, AI photos, or vague hero text
-  No emoji icons, em dashes, or "made with AI" tags
-  No crazy scroll or custom cursor animations

## 🏗️ Core Architecture & SEO
-  Custom domain connected
-  Meta Title and Meta Description per page
-  Open Graph tags and images for link previews
-  Favicon set uploaded
-  Robots.txt and XML Sitemap generated
-  Google Search Console and Bing Webmaster Tools setup
-  `llms.txt` file added for AI crawler compatibility
-  Schema Markup (JSON-LD) implemented
-  UTM tracking configured
-  Google Analytics (or equivalent) installed

## 🧭 UI/UX & Navigation
-  Dark mode toggle
-  Sticky headers and Mobile Menu
-  Search functionality
-  Scroll progress bar and Back to top button
-  Expandable FAQ section
-  Print style sheet configured
-  Mobile breakpoints and Sticky Mobile CTA
-  CTA placed above the fold
-  Custom 404 page

## 🖱️ Forms & Interactive States
-  Loading animations, buffering screens, and hover states
-  Form success and error states clearly defined
-  Password visibility toggle
-  Copy buttons for code snippets or keys
-  Confirmation modals for destructive actions
-  Dedicated Thank-you page post-submission

## ⚖️ Legal, Trust & Security
-  Privacy Policy and Terms & Conditions pages
-  Simple Cookie banner implemented
-  Last updated date visible on content/legal pages
-  Real contact address listed
-  Strict HTTPS/HSTS enforced
-  Content Security Policy (CSP) headers set

## ⚡ Performance & Accessibility
-  WebP or AVIF next-gen image formats used
-  Alt text applied to every image
-  Lazy loading enabled for below-the-fold media
-  Skip to content link for keyboard navigation
-  ARIA labels added to toggles and interactive elements
-  Semantic HTML5 structure applied
-  Web App Manifest and basic Service Worker for offline support
